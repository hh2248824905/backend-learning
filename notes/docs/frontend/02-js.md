## 0. 为什么 ES6 是 Vue 的前置课

Vue 代码里几乎每一行都在用 ES6：

```js
import { ref, computed } from 'vue'          // ES Module + 解构
const todos = ref([])                        // const + 箭头函数
const active = computed(() => todos.value.filter(t => !t.done))  // 数组方法 + 箭头函数
const { title, done } = item                 // 对象解构
```

看不懂这些，`<script setup>` 就是天书。

## 1. 变量：`var` / `let` / `const`

| | 作用域 | 重复声明 | 变量提升 | 能否重新赋值 |
|---|---|---|---|---|
| `var` | 函数级 | 允许 | 有（值为 `undefined`） | 能 |
| `let` | 块级 `{}` | 报错 | 有（暂时性死区） | 能 |
| `const` | 块级 `{}` | 报错 | 有（暂时性死区） | **不能重新赋值** |

**实操结论**：默认 `const`，需要改就换 `let`，`var` 不写。

⚠️ `const` 锁的是**绑定**，不是内容：

```js
const arr = [1, 2]
arr.push(3)        // ✅ 允许，改的是内容
arr = [4, 5]       // ❌ TypeError: Assignment to constant variable
```

这也是 Vue 里 `const todos = ref([])` 能正常工作的原因——你改的是 `todos.value` 内部数据，从没重新赋值 `todos`。

## 2. 函数

### 2.1 箭头函数与 `this`

```js
const add = (a, b) => a + b       // 表达式体，自动 return
const log = (x) => { console.log(x) }   // 语句体，要手写 return
```

**核心差异**：箭头函数没有自己的 `this`，它捕获定义时外层的 `this`。

| 场景 | 普通函数 | 箭头函数 |
|---|---|---|
| 作为对象方法 | `this` = 调用者 | `this` = 外层作用域（通常是错的） |
| 作为回调（`setTimeout`、`.map`） | `this` 可能丢失 | `this` = 外层，正是想要的 |
| Vue 选项式 API 的 `methods` | ✅ 用普通函数 | ❌ 拿不到 `this.count` |

这也是为什么 `E:\qianduan\01-vue-literal\index.html` 里 computed 写的是：

```js
computed: {
  evenOrOdd() {                          // ← 必须普通函数
    return this.count % 2 === 0 ? '偶数' : '奇数'
  }
}
```

写成箭头函数 `evenOrOdd: () => this.count...` 就取不到 `count`。

而组合式 API（`<script setup>`）里全是箭头函数——因为不再依赖 `this`，数据都从 `ref` 变量拿。

### 2.2 默认参数与剩余参数

```js
function greet(name = '访客') { return `你好，${name}` }
function sum(...nums) { return nums.reduce((a, b) => a + b, 0) }
```

## 3. 字符串与解构

### 3.1 模板字符串

```js
const msg = `未完成 ${activeCount} 项，共 ${todos.length} 项`
```

**反引号**，不是引号；`${}` 里可以写任意表达式、调用函数。

### 3.2 解构赋值

```js
// 对象
const { name, age, address: { city } } = student    // 支持嵌套，可重命名
const { name: userName = '匿名' } = props           // 默认值

// 数组
const [first, , third] = list                       // 逗号跳位

// 函数参数直接解构（Vue 组件 props 高频用法）
function show({ title, done }) { ... }
```

### 3.3 展开与收集

```js
const merged = { ...defaults, ...userConfig }   // 对象合并，后者覆盖前者
const copy = [...todos]                          // 浅拷贝数组
const item = { ...todo, done: !todo.done }       // 不可变更新（React 风格）
```

Vue 3 的响应式系统基于 Proxy，直接改属性也能触发更新，所以不必强行用展开做不可变更新——但在 `watch` 里比较新旧值时要注意：**浅拷贝的对象引用变了，深拷贝没变**。

## 4. 数组方法：Vue 列表操作的肌肉记忆

TodoList 案例里全部用到：

```js
todos.value.filter(t => !t.done)                       // 筛选：未完成项
todos.value.find(t => t.id === id)                     // 查找：按下标找对象
todos.value.map(t => t.id)                             // 映射：取 id 数组
todos.value.push({ id: nextId++, title, done: false }) // 追加
todos.value = todos.value.filter(t => t.id !== id)     // 删除：过滤后重新赋值
```

| 方法 | 返回值 | 改原数组？ | 典型用途 |
|---|---|---|---|
| `filter` | 新数组 | 否 | 按条件筛选、删除元素 |
| `map` | 新数组 | 否 | 转换结构 |
| `find` | 元素或 `undefined` | 否 | 按 id 找对象 |
| `findIndex` | 下标或 `-1` | 否 | 找到位置再改 |
| `some` / `every` | 布尔 | 否 | 存在性 / 全满足 |
| `reduce` | 累积值 | 否 | 求和、计数、分组 |
| `push` / `pop` / `splice` | — | **是** | 增删改 |
| `sort` / `reverse` | 原数组 | **是** | 排序 |

⚠️ `sort()` 默认按**字符串**排序，数字排序必须传比较函数：`nums.sort((a, b) => a - b)`。这是经典坑。

## 5. 异步：Promise 与 async/await

接口调用一定会用到。

```js
// Promise 链式
fetch('/config/student')
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err))

// async/await（同一件事，读起来像同步）
async function loadStudent() {
  try {
    const res = await fetch('/config/student')
    if (!res.ok) throw new Error(`HTTP ${res.status}`)
    return await res.json()
  } catch (err) {
    console.error('加载失败', err)
  } finally {
    console.log('请求结束')
  }
}
```

**要点**：
- `await` 只能在 `async` 函数里用（顶层 await 在 ES Module 里合法，但兼容性看环境）
- `await` 等的是 Promise，非 Promise 值会被自动包装
- VS Code / IDEA 里 `Ctrl+Shift+右键` 看不到断点位置时，八成是忘了 `await`，拿到的是 Promise 而不是数据

## 6. 模块化

```js
// 导出（一个文件一个模块）
export const STORAGE_KEY = 'vue-todos'
export function add(a, b) { return a + b }
export default { /* 整个对象作为默认导出 */ }

// 导入
import Vue, { ref, computed } from 'vue'    // 默认导出 + 具名导出混用
import App from './App.vue'
```

Vue 项目里的分层约定：

```
src/
├── main.js           入口：createApp(App).mount('#app')
├── App.vue           根组件
├── components/       可复用组件（具名导出/默认导出）
├── api/              接口封装（导出函数）
└── utils/            工具函数（导出函数）
```
